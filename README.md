# EK's Remote – updates

Published files for the EK's Remote Android app (phone remote for a TCL Google TV).

- `EKs-Remote.apk` – latest app. Download on the Android phone and tap to install.
- `version.json` – latest version number; the app checks it to offer one-tap updates.
- `ui/index.html` – the remote's screen; the app loads the newest one automatically.

The app's source code is kept in a separate private repository.
